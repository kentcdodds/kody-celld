# Security

Please report security issues **privately** — do not open a public issue or PR
for an unfixed vulnerability.

1. Prefer [GitHub private vulnerability reporting](https://github.com/kentcdodds/kody-celld/security/advisories/new)
   (Security tab → **Report a vulnerability**).
2. If that is unavailable, email [me@kentcdodds.com](mailto:me@kentcdodds.com)
   with enough detail to reproduce (affected version/tag or commit, deployment
   mode, and steps).

We will acknowledge the report and coordinate a fix and disclosure.
